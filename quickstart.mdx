## 2. Send your first bill

POST an energy bill to the upload endpoint as `multipart/form-data`, with your key in the `X-API-Key` header. The API accepts electricity, gas and LPG bills from retailers across Australia, NZ, the UK, the USA and Canada.

<CodeGroup>
  ```python Python
  import requests

  response = requests.post(
      "https://termina.io/api/v2/public/bills/upload/",
      headers={"X-API-Key": "YOUR_API_KEY"},
      files={"file": open("energy_bill.pdf", "rb")},
  )

  data = response.json()
  print(data)
  ```

  ```javascript Node.js
  import fs from "fs";

  const form = new FormData();
  form.append("file", new Blob([fs.readFileSync("energy_bill.pdf")]), "energy_bill.pdf");

  const response = await fetch("https://termina.io/api/v2/public/bills/upload/", {
    method: "POST",
    headers: { "X-API-Key": "YOUR_API_KEY" },
    body: form,
  });

  const data = await response.json();
  console.log(data);
  ```

  ```bash cURL
  curl -X POST https://termina.io/api/v2/public/bills/upload/ \
    -H "X-API-Key: YOUR_API_KEY" \
    -F "file=@energy_bill.pdf"
  ```
</CodeGroup>

The endpoint detects the energy type (electricity, gas or LPG), the retailer and the bill layout automatically. The file is the only input.

### Response structure at a glance

| Field | What it contains |
| --- | --- |
| `bill_uuid` | Unique ID for the processed bill |
| `energy_data.fuel_type` | `elec`, `gas` or `lpg` |
| `energy_data.site_identifier` | The NMI (electricity) or MIRN (gas) |
| `energy_data.retailer_name`, `account_number`, `account_name`, `supply_address` | Account and site details |
| `energy_data.billing_period` | Start date, end date and number of days |
| `energy_data.charges` | Every line item, with its `classification` (for example `Retail Peak`, `Supply`, `Network Anytime Demand`), rate steps, quantities and amounts |
| `energy_data.meter_reads` | Meter readings, where shown on the bill |
| `energy_data.total_amount`, `total_due`, `due_date` | Bill totals |
| `validation_issues` | Any problems found, each with `severity` (`WARNING`, `ERROR` or `ERROR_IGNORABLE`), `field` and `message` |

## 4. Compare the site's rates

The bill gives you the two inputs the [business electricity rates API](/rates/overview) needs: the site's NMI and its usage. Annualise the usage, then ask for the cheapest rates for that exact site:

```python Python
bill = data["energy_data"]

# Annual usage: kWh on the bill, scaled from the billing period to a year
kwh = sum(
    step["quantity"] or 0
    for charge in bill["charges"]
    for step in charge["rate_steps"]
    if step.get("quantity_unit") == "kWh"
    and charge["classification"].startswith("Retail")
)
annual_kwh = round(kwh / bill["billing_period"]["days"] * 365)

rates = requests.get(
    "https://api.termina.com/v1/rates",
    params={"nmi": bill["site_identifier"], "usage_kwh": annual_kwh},
).json()

print(rates["summary"]["cheapest"])
```

`summary.cheapest` is the cheapest rate for that site, with its % difference from the Default Market Offer. Compare it with what the bill is costing the business today. See [Using Termina with AI agents](/rates/ai-agents) for the full flow.

## Frequently asked questions

<AccordionGroup>
  <Accordion title="What file formats does the API accept?">
    Send the bill as `multipart/form-data` under the `file` field. Both digital PDFs from retailer portals and scanned or photographed paper bills are supported.
  </Accordion>

  <Accordion title="How long does extraction take?">
    Most bills are processed in under 3 seconds. Complex multi-page bills or low-quality scans may take slightly longer. The API responds synchronously, with no polling or webhooks required.
  </Accordion>

  <Accordion title="Which energy types can the API extract?">
    Electricity, gas and LPG bills. The extraction covers network charges, retail charges, environmental levies, market charges and demand charges, with tariff rate steps and time-of-use breakdowns where they're on the bill.
  </Accordion>

  <Accordion title="Can the API extract time-of-use tariff data?">
    Yes. Where time-of-use pricing is on the bill, Termina extracts peak, off-peak and shoulder rates and consumption separately, including each charge's rate steps and the kWh consumed in each period.
  </Accordion>

  <Accordion title="What happens if a bill can't be fully parsed?">
    `energy_data` is `null` and `validation_issues` describes what went wrong. Partial extractions return the data that was read, with warnings on uncertain fields, so you always know what you can trust.
  </Accordion>

  <Accordion title="How does bill validation work?">
    Every extraction cross-checks the extracted charges against the bill total, verifies the billing period dates, flags unusually high or low usage, and checks tariff rates fall within expected ranges for the retailer and region. Issues are returned in `validation_issues`.
  </Accordion>

  <Accordion title="How do I authenticate API requests?">
    Include your API key in the `X-API-Key` request header. You can generate a free key instantly at [app.termina.io](https://app.termina.io), with no credit card required.
  </Accordion>

  <Accordion title="What are the rate limits?">
    Free tier accounts can process up to 50 bills in total. Pro accounts have configurable rate limits based on your plan. The API returns a `429` status code with a `Retry-After` header if you exceed your limit.
  </Accordion>

  <Accordion title="Can I find cheaper electricity rates for the bill's site?">
    Yes. Pass the bill's `site_identifier` (the NMI) and annual usage to the [business electricity rates API](/rates/overview) to get the cheapest rates for that site, compared with the Default Market Offer. See step 4 above.
  </Accordion>
</AccordionGroup>
