openapi: "/openapi-rates.yaml GET /v1/rates"

Returns every costed business electricity plan for a location, ranked by annual cost, with the regulated benchmark costed at the same usage and a `summary` block that answers "what's the cheapest rate here?" directly.

- **Base URL:** `https://api.termina.com`
- **Authentication:** none
- **Rate limit:** 120 requests a minute per IP address
- **Caching:** up to 1 hour. Rates are checked daily

## Location

Pass **one** location. The most specific wins: `nmi`, then `postcode`, `distributor`, `city`, `state`. `distributor` can also narrow a postcode, city or state to one network. See [Choosing a location](/rates/locations) and [Supported networks, cities and states](/rates/networks-and-cities).

## Examples

<Tabs>
  <Tab title="Postcode">
    The cheapest rates for a postcode, at the default 10,000 kWh a year:

    ```bash
    curl "https://api.termina.com/v1/rates?postcode=2000"
    ```
  </Tab>
  <Tab title="NMI and usage">
    The most precise request: the site's NMI and annual usage, both from a bill:

    ```bash
    curl "https://api.termina.com/v1/rates?nmi=4102012345&usage_kwh=25000"
    ```
  </Tab>
  <Tab title="Time of use and demand">
    Re-cost time-of-use and demand plans with the site's own profile:

    ```bash
    curl "https://api.termina.com/v1/rates?postcode=3000&usage_kwh=40000&peak_share=0.4&shoulder_share=0.3&max_demand_kw=25"
    ```
  </Tab>
  <Tab title="Split postcode">
    2620 is served by two networks. Without `distributor` you get plans for both, flagged with `ambiguous_location`; with it, one network:

    ```bash
    curl "https://api.termina.com/v1/rates?postcode=2620&distributor=evoenergy"
    ```
  </Tab>
  <Tab title="State or city">
    Every network in the area, ranked together:

    ```bash
    curl "https://api.termina.com/v1/rates?state=NSW"
    curl "https://api.termina.com/v1/rates?city=brisbane"
    ```
  </Tab>
  <Tab title="Public plans only">
    Only plans any business can sign up to directly:

    ```bash
    curl "https://api.termina.com/v1/rates?distributor=ausgrid&offer_source=public&limit=50"
    ```
  </Tab>
</Tabs>

## Reading the response

| Field | What it holds |
| --- | --- |
| `summary` | The answer: cheapest option overall, cheapest public plan with its retailer, cheapest buying group rate, % vs the benchmark, coverage and the date checked |
| `plans` | Every costed plan on this page, ranked by annual cost |
| `benchmark` | The network's DMO, VDO or Aurora regulated tariff, costed at the same usage as the plans. Null for the ACT and Ergon |
| `usage` | The usage the plans are costed at, and which inputs were defaults |
| `location` | How the location was resolved: networks, state, suburbs, and whether it's ambiguous |
| `by_network` | Usage, benchmark and stats for each network, when a response covers several |
| `stats` | Counts, lowest prices and rate percentiles, when a response covers one network |
| `pagination` | Page, totals and `next_cursor` |
| `warnings` | Anything to tell the user, written to be shown as is |
| `page_url` | The matching page on termina.com, to cite or send the user to |

The fields you'll use most:

<ResponseField name="summary.cheapest" type="object">
  The cheapest option overall. Always the same as the first plan on page 1. `offer_source` is `termina_buying_group` (no retailer named) or `public` (with retailer, plan name and plan ID).
</ResponseField>

<ResponseField name="summary.cheapest_public" type="object | null">
  The cheapest public plan, with retailer, plan name, plan ID, annual cost and % vs the benchmark.
</ResponseField>

<ResponseField name="plans[].annual_cost_inc_gst" type="number">
  The plan's cost for a year at `usage.annual_kwh`, incl. GST. For buying group rates this is before Termina's fee.
</ResponseField>

<ResponseField name="plans[].vs_standing_offer_pct" type="number | null">
  The plan vs the network's DMO or VDO at the same usage, in %. Negative means cheaper. Null where there's no benchmark.
</ResponseField>

<ResponseField name="summary.checked_at" type="string">
  The date the rates were checked. Quote it alongside any figure.
</ResponseField>

## Pagination

Plans come back 10 per page by default (`limit` up to 50). While `pagination.has_more` is true, pass `pagination.next_cursor` back as `cursor`, with the same other parameters. When a response covers several networks, the cursor keeps each network's place, so you get every plan exactly once.

## Errors

Errors return `{ "error": { "code", "message", "details" } }` with status 400 (invalid input), 404, 422 (`out_of_coverage`, for example WA or NT), 429 (rate limited) or 503 (try again shortly). See [Errors and warnings](/rates/errors-and-warnings) for every code.

<RequestExample>
```bash cURL
curl "https://api.termina.com/v1/rates?distributor=ausgrid&usage_kwh=10000"
```

```python Python
import requests

r = requests.get(
    "https://api.termina.com/v1/rates",
    params={"distributor": "ausgrid", "usage_kwh": 10000},
)
summary = r.json()["summary"]
print(summary["cheapest"], summary["cheapest_public"])
```

```javascript Node.js
const res = await fetch(
  "https://api.termina.com/v1/rates?distributor=ausgrid&usage_kwh=10000"
);
const { summary } = await res.json();
console.log(summary.cheapest, summary.cheapest_public);
```
</RequestExample>
